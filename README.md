# 📄 AI PDF Chatbot (RAG-Based Document QA System)

## 🚀 Overview

This project is an end-to-end **Retrieval-Augmented Generation (RAG)** system that allows users to interact with PDF documents using natural language.

Users can upload a PDF, ask questions, and receive accurate answers generated by an LLM based **only on the document content**.

---

## 🎯 Key Features

* 📥 Upload and process PDF documents
* ✂️ Intelligent text chunking with overlap
* 🧠 Local embeddings using Ollama (`nomic-embed-text`)
* ⚡ Fast similarity search using FAISS
* 🤖 LLM-powered answers using Groq (LLaMA models)
* 💬 Interactive chatbot interface (Streamlit UI)
* 🔒 No dependency on OpenAI (fully free pipeline)

## 🔄 How It Works (Pipeline)

```
PDF → Text Extraction → Chunking
        ↓
Embeddings (Ollama)
        ↓
FAISS Vector Index
        ↓
User Query
        ↓
Query Embedding (Ollama)
        ↓
Similarity Search (Top K Chunks)
        ↓
Groq LLM (Context + Question)
        ↓
Final Answer
```

## 🛠️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/pdf-chatbot.git
cd pdf-chatbot
```

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

Or manually:

```bash
pip install streamlit faiss-cpu python-dotenv PyPDF2 requests numpy
```

---

### 3️⃣ Install & Run Ollama

Download and install Ollama from:
https://ollama.com

Then run:

```bash
ollama serve
ollama pull nomic-embed-text
```

---

### 4️⃣ Set Up Groq API Key

Create a `.env` file in the root folder:

```
pdf-chatbot/
│
├── .env
```

Inside `.env`:

```
GROQ_API_KEY=gsk_your_api_key_here
```

---

### 5️⃣ Run the Application

#### 🔹 Option A: Streamlit UI (Recommended)

```bash
streamlit run app.py
```

👉 Opens in browser:
http://localhost:8501

---

#### 🔹 Option B: CLI Chatbot

```bash
python main.py
```

## ⚠️ Important Notes

* Works best with **text-based PDFs**
* Scanned PDFs require OCR (not implemented)
* Ensure Ollama is running before starting the app
* Do not commit `.env` file to GitHub

## 📈 Improvements Implemented

* Overlapping chunking for better context retention
* Top-K retrieval (k=3) for higher accuracy
* Prompt engineering to avoid hallucinations:

  > If answer not in context → return "Not found"
