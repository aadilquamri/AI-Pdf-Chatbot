# 📄 AI PDF Chatbot (RAG)

## Overview
A Retrieval-Augmented Generation (RAG) system that allows users to query PDF documents using LLMs.

## Features
- PDF text extraction
- Chunking & embeddings (Ollama)
- Vector search (FAISS)
- LLM response (Groq)

## Tech Stack
- Python
- FAISS
- Ollama
- Groq API

## Example Questions
- "What is the main topic?"
- "Summarize the document"

## How to Run
1. ollama serve
2. python main.py
